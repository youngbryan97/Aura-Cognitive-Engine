# Aura Cognitive Engine: current project links

Aura's maintained source and documentation are in
[youngbryan97/aura](https://github.com/youngbryan97/aura). This older repository
contains a landing page rather than the current engine implementation.

Aura is a local AI research project built around a language model, lasting
records, attention, action control and ongoing internal state. The practical
goal is an assistant that can keep track of work, use relevant history, explain
its actions and remain responsive while it works.

## The subjecthood research

[ISC explained](https://github.com/youngbryan97/aura/blob/main/docs/ISC_EXPLAINED.md)
introduces the experiments. The completed seed-23 run passed 22 of 24
operational checks under ISC-v6, with positive content and withheld-report
outputs. A later isolation defect means those paired findings need rechecking.
The carrier and split-system control questions remain unsettled.
Read [current status](https://github.com/youngbryan97/aura/blob/main/docs/ISC_STATUS.md)
for the exact measurements and later developments.

The separate
[proof-kernel repository](https://github.com/youngbryan97/aura-consciousness-proof-kernel)
is a small demonstration of earlier components. Its name does not describe a
completed proof of consciousness, and this landing page supplies no additional
experimental result.
